# Amazon Homepage Clone

A responsive Amazon homepage clone built using HTML and CSS to practice frontend web development fundamentals.

## Features

- Amazon-inspired navigation bar
- Search bar UI
- Hero banner section
- Product category cards
- Footer section
- Clean layout using Flexbox
- Custom styling with CSS

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

## Purpose

This project was created as a learning exercise to strengthen my understanding of:

- HTML page structure
- CSS styling
- Flexbox layout
- Positioning and spacing
- Responsive design fundamentals
- Real-world UI recreation

## Project Preview

Amazon homepage inspired user interface with product sections, navigation menu, and footer.
